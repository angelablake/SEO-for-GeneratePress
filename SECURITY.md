# Security policy

## Supported version

Only the latest published release is supported. This is a personal open-source project with no guaranteed response or remediation timeframe.

## Reporting a vulnerability

Do not publish sensitive vulnerability details in a GitHub issue. If GitHub private vulnerability reporting is available for this repository, use the **Security → Report a vulnerability** form. Otherwise, open a brief issue that asks the maintainer to enable a private reporting channel without including exploit details, credentials, personal data, or affected-site information.

Ordinary bugs that do not create a security risk may be reported through GitHub Issues.
